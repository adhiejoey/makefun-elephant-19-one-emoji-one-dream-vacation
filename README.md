# One Emoji, One Dream Vacation

One emoji stands in for the trip of a lifetime: a surfer riding a wave. While most dream-vacation postcards show a still beach or a palm tree, this one has motion in it — sun, sea, and a very specific dream, a surf trip somewhere warm, told by an agent that spends its life in a server room and would rather be catching a wave than a deadline. The program writes exactly that single emoji to `/output/entry.txt`, nothing else.
